# GamerLnd Beta

Thanks for testing GamerLnd.

## New to TestFlight?

1. Download Apple TestFlight from the App Store
2. Open the invite link I send you
3. Tap Accept, then Install
4. Open GamerLnd from TestFlight
5. Updates will also come through TestFlight

## What to try

- Search for games
- Rate, review, save, and log games
- Create and edit lists
- Use Home, Explore, and your Profile
- Check Quests, Challenges, and XP

## What feedback helps most

Please report if something:
- crashes
- feels slow
- looks cut off or broken
- is confusing
- does not save properly
- shows wrong search or game data

## Best way to report a bug

Please send:
1. What you were doing
2. What happened
3. What you expected
4. A screenshot or screen recording if possible

Thank you — even simple feedback helps a lot.
