# GamerLnd Beta Feedback Guide

Thanks for helping test GamerLnd.

This is not a formal QA test. You do not need to try everything or write technical reports. The most helpful thing is just using the app normally and telling us when something feels off, confusing, slow, broken, or especially great.

## What kind of feedback helps most

The best feedback usually falls into one of these buckets:

- Something is broken
- Something is confusing
- Something feels slow or clunky
- Something looks weird or out of place
- Something feels really good and should stay

## The most helpful things to try

If you only have a little time, these are the most helpful areas to use:

1. Create an account and set up your profile
2. Search for games
3. Rate, review, save, and add games to lists
4. Create and edit lists
5. Use the Home feed, Explore, and your Profile
6. Open the Quest Board / Challenges / XP area
7. Check notifications and activity

## Good feedback examples

Instead of:
- "It broke"

Try:
- "I searched for Halo, tapped a result, and the screen froze for about 5 seconds."
- "I made a ranked list, but after tapping Create I wasn’t sure what happened next."
- "The profile page felt clean and easy to use."
- "The comments box covered part of the screen when the keyboard came up."

## If you find a bug, send these 4 things

Please include:

1. What you were trying to do
2. What happened
3. What you expected to happen
4. If possible, a screenshot or screen recording

Helpful example:
- "I was editing a game log review. When I opened the keyboard, the save button went off screen. I expected the editor to stay fully visible."

## Questions to keep in mind while using the app

You do not need to answer all of these. They are just helpful prompts.

### Overall
- Did the app feel fun to use?
- Did anything feel confusing?
- Did anything feel slow?
- Did anything feel especially polished or satisfying?

### Search
- Did search results feel relevant?
- Was it easy to find the game you wanted?
- Did any result feel random, wrong, or misleading?

### Logging games
- Was it easy to understand what it means to log a game?
- Did rating, reviewing, saving, and adding to lists feel natural?
- Did the game log screens feel clear?

### Lists
- Was it easy to create a list?
- Did ranked and tier list options make sense?
- Did editing a list feel smooth?

### Profile / social
- Did your profile feel clear and organized?
- Did the feed make sense?
- Did notifications/activity feel useful?

### Rewards / progress
- Did quests, challenges, and XP feel understandable?
- Did anything in the G tab feel confusing or crowded?

## What to definitely report

Please report any time you notice:

- app crashes
- freezing or major lag
- blank screens
- buttons not working
- keyboard covering important UI
- overlays looking cut off
- wrong game data
- actions not saving
- anything that feels unexpectedly confusing

## Very helpful extra feedback

If you want to go a little further, these are especially helpful:

- "My favorite part of the app was..."
- "The most confusing part of the app was..."
- "One thing I’d improve before release is..."
