# GamerLnd Quest Board Beta Test Checklist

Use this founder account checklist to quickly validate the new Quest Board tracking.

## Reset assumptions
- Account is freshly wiped
- Founder tools are available if you need to reveal hidden tiles
- After each action, open `Profile > G` and check the relevant tile's progress/completion

## Tier 1: Fast sanity checks

### 1. First Search
- Go to `Explore > Games`
- Search any game once
- Expected:
  - `First Search` completes

### 2. Save & Continue
- Save one game from Explore or Game Detail
- Expected:
  - `Save & Continue` completes

### 3. First Rating
- Open a game and save a log with a rating
- Expected:
  - `First Rating` completes

### 4. Baby Critic
- Add a review of at least 50 characters to a log
- Expected:
  - `Baby Critic` completes

### 5. The First of Many
- Create one list
- Expected:
  - `The First of Many` completes

### 6. List Habit
- Add 10 total games to any lists
- Expected:
  - `List Habit` completes

### 7. Collection Habit
- In the same app session:
  - search a game
  - save a game
  - add a game to a list
- Expected:
  - `Collection Habit` completes

### 8. Housemaid
- Flag 1-2 search results while testing
- Expected:
  - progress increases on `Housemaid`

## Tier 2: High-value progression checks

### 9. Wishlist Wizard
- Save 20 games
- Expected:
  - `Wishlist Wizard` completes

### 10. Perfect Ten
- Rate one game `10.0`
- Expected:
  - secret quest `Perfect Ten` unlocks

### 11. Double Take
- Rate two games back-to-back with the exact same score
- Expected:
  - secret quest `Double Take` unlocks

### 12. Silent Shelf
- Save 20 games without rating them first
- Expected:
  - secret quest `Silent Shelf` unlocks

### 13. Procrastination
- Create a list titled exactly `Backlog` or `Back Log`
- Add at least one game to it
- Expected:
  - `Procrastination` completes

### 14. The Curator
- Add 50 games to one list
- Expected:
  - `The Curator` completes

### 15. A Bit Much
- Add 100 games to one ranked list
- Expected:
  - `A Bit Much` completes

## Tier 3: Metadata-sensitive checks

### 16. The Big 'N' Approves
- Rate Nintendo games until progress moves as expected
- Suggested games:
  - Mario, Zelda, Metroid, Pokemon, Smash
- Expected:
  - progress increments only on Nintendo-related titles

### 17. No Limits
- Review games across PlayStation 1, 2, 3, 4, and 5
- Expected:
  - progress counts distinct PS generations

### 18. What's Your K/D?
- Rate 10 FPS games
- Expected:
  - progress increments only on FPS-tagged titles

### 19. 8-bit Tourist
- Save 10 games released in the 1980s
- Expected:
  - progress increments only for 1980s titles

### 20. Alpha Zeta
- Save games with different starting letters
- Expected:
  - progress reflects distinct A-Z initials only

## Tier 4: Streak checks

### 21. Rhythm Writer
- Write one qualifying review on 7 different days
- Expected:
  - progress reflects longest daily review streak

### 22. Library Rhythm
- Save at least one game on 7 different days
- Expected:
  - progress reflects longest save streak

## Public/private list structure checks

### 23. Keepsake
- Create at least one private:
  - standard list
  - ranked list
  - tier list
- Expected:
  - `Keepsake` completes

### 24. Tier Architect
- Create 10 public tier lists
- Expected:
  - `Tier Architect` completes

### 25. Show Off
- Create 10 public ranked lists
- Expected:
  - `Show Off` completes

### 26. Public Opinion
- Create 5 public standard, 5 public ranked, and 5 public tier lists
- Expected:
  - progress tracks the minimum completed bucket

## Likes/views/social checks

### 27. Participation Trophy
- Like different users' logs
- Expected:
  - progress reflects unique liked log count

### 28. Superfan
- Open many games from the same developer/publisher family
- Expected:
  - progress reflects repeated views within the same company group

## Board-level check

### 29. GamerLnd Citizen
- Complete many different quests across categories
- Expected:
  - progress increases as completed quest count grows

## If something misfires
Capture these 4 things:
- quest name
- exact action you took
- game/list used
- what happened vs what you expected

That will make the next fix pass much faster.
